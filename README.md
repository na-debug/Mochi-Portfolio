# Mochi-Portfolio


A simple personal portfolio website built using HTML, CSS, and JavaScript. This project is designed to showcase projects, skills, and contact information in a clean and modern layout.

## Overview

Mochi Portfolio is a lightweight portfolio website created for personal branding and project display. It is easy to customize, responsive, and suitable for showcasing work, achievements, and skills.

## Features

- Responsive layout for desktop, tablet, and mobile
- Modern portfolio design
- Section for introduction and about me
- Project showcase area
- Skills section
- Contact information / social links
- Lightweight and fast-loading website

## Tech Stack

- HTML
- CSS
- JavaScript
